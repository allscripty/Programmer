Pointers are variables that store the memory address of another variable. Here is the classic swap function:

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    swap(&x, &y);
    printf("x: %d, y: %d", x, y);
    return 0;
}
```

C is a powerful, general-purpose programming language developed in the early 1970s by Dennis Ritchie. It is widely used for system programming, developing operating systems, embedded systems, and high-performance applications.

## Pre-Requisites & Setup

To write and compile C programs, you need a C compiler.

- **Windows**: Install [Dev C++](https://sourceforge.net/projects/orwelldevcpp/) or MinGW-w64.
- **macOS / Linux**: You can use the built-in `gcc` or `clang` compilers available via the terminal.

## Topics Covered

1. **Basic Programming:**
   - Syntax, Constants, Variables
   - Keywords, Datatypes, Operators
   - Header files, Escape keys
   - Preprocessor directives, Data Conversion
   - Strings, Control statements (Loops, selections)
   - Arrays, Matrices (1-D, 2-D)
2. **Medium Complexity Concepts:**
   - User-defined functions
   - Structures, Unions
   - Pointers
   - File handling

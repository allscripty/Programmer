CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML or XML. It controls the layout of multiple web pages all at once, which makes it an incredibly powerful tool for developers.

While HTML forms the structure of a site, CSS is what gives a site its visual design and user interface layout.

## Pre-Requisites & Setup

Frontend development only requires a text editor and a web browser.

- **Web Browser**: A modern browser like Google Chrome, Brave, Firefox, or Edge.
- **Text Editor**: [Visual Studio Code](https://code.visualstudio.com/) or Sublime Text.

**Key Concepts:**
- **Selectors**: Patterns used to select the elements you want to style.
- **Properties**: The stylistic characteristics (color, background, font-size, etc.)
- **Values**: The settings for those properties.

**PHP (Hypertext Preprocessor)** is a popular **server-side scripting language** designed for web development. It is used to create dynamic and interactive websites.

## Pre-Requisites & Setup

Because PHP is a server-side scripting language, it requires a local server environment to run on your machine.

- **Local Server**: [XAMPP](https://www.apachefriends.org/index.html), Laragon, or WampServer.
- **Text Editor**: Visual Studio Code or Sublime Text.

### How to run PHP code (with XAMPP)

1. Open your code editor and write your PHP code.
2. **Crucial Step**: Save your `.php` file inside the `C:\xampp\htdocs\` folder.
3. Open the **XAMPP Control Panel** and start **Apache** and **MySQL**.
4. Open your web browser and navigate to `http://localhost/your_file.php`.

*(If you saved it inside a subfolder, e.g., `C:\xampp\htdocs\my_project\your_file.php`, then navigate to `http://localhost/my_project/your_file.php`)*

To view database results, navigate to `http://localhost/phpmyadmin` in your browser.

## Key Features of PHP
- Open-source and free  
- Easy to learn and use  
- Platform independent (runs on Windows, Linux, macOS)  
- Strong database support  
- Large community support

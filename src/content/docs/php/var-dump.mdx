### Code Example

```php
<?php

// Declaring integer variable
$x = 5; 

// Declaring string variable
$y = "Hello, World!";

// Declaring float variable
$z = 5.55;

// Using var_dump to display the type and value of the variables
var_dump("The datatype and value of x is: $x");
var_dump("The datatype and value of y is: $y");
var_dump("The datatype and value of z is: $z");
?>
```
